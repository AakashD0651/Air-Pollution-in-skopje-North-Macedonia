
# Air Pollution in Skopje, North Macedonia

Exploratory data analysis of air quality in Skopje using 10 years of readings from 6 monitoring stations, with a focus on seasonal and regional pollution patterns.

## Key Findings
- Analyzed **87,600+ data points** from **6 monitoring stations** over **10 years**
- Identified **3 peak pollution months**
- Winter pollution is **29% higher** than in other seasons
- Flagged **210+ high-risk days per year**, supporting data-driven recommendations for environmental policy

## Tech Stack
- Python
- Pandas, NumPy (data cleaning and analysis)
- Matplotlib, Seaborn (visualization)
